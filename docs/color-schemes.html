Colour scheme options

Eight directions, each rendered with identical components so the only difference is the palette. The ratios underneath each one are computed live, not typed in: body text and button label against their backgrounds, at the WCAG thresholds of 4.5 and 3.0.

Read this before choosing. Colour is one of six axes. We already learned that changing the accent while keeping warm paper, a serif and Inter produces the same website in a different colour, which is exactly what was wrong before. Whichever scheme you pick here, the typefaces and the shape have to change with it. The scheme column on the right says what each one frees up.
